| # | 계획 항목 | 계획 내용 | 결과 | 비고 |

### 🟡 부분 미적용 항목 설명

| 미적용 항목 | 왜 안 했나? | 영향도 | 향후 계획 |
|:---|:---|:---:|:---|
| ARIA 속성 추가 | 현재 시스템은 주로 PC 브라우저에서 사용. 시각장애인 사용자가 없는 환경. 줌 허용만으로도 기본 접근성 충족 | 🟢 낮음 | 접근성 감사 시 추가 검토 |
| 포커스 트랩 / Skip nav | 위와 동일. 키보드 전용 사용자가 거의 없음 | 🟢 낮음 | 필요 시 추가 |

> **소결**: 보안 관련 항목은 **100% 완료**. 접근성은 가장 중요한 "줌 허용"을 완료하고, ARIA·포커스 트랩은 현재 사용 환경상 우선순위가 낮아 보류.
