## Phase 1: 🔴 긴급 보안·법적 필수 사항

### 1-1. 관리자 코드 보안 강화
- **문제**: `ADMIN_CODE = "ADMIN777"` 소스코드 평문 노출
- **조치**: SHA-256 해시 비교 방식으로 변경 + 시도 횟수 제한(5회/30초 잠금)
- **대상 파일**: `lost_and_found.html`, `lost_and_found_admin.html`

### 1-2. 개인정보 처리방침 페이지 신규 생성
- **문제**: 개인정보보호법 제30조 필수 게시 의무 미이행
- **조치**: `privacy_policy.html` 신규 생성
- **내용**: 수집항목, 수집목적(유실물법 근거), 보유기간, 파기절차, 위탁사항(Firebase/Google)

### 1-3. 수령 완료 화면 법적 근거 안내 문구
- **문제**: 개인정보 수집 근거 안내 없음
- **조치**: 수령 완료 처리 영역에 유실물법 근거 안내 1줄 추가
- **변경**: ~~동의 체크박스~~ → 법적 근거 고지 문구 (유실물법 제11조)
- **대상 파일**: `lost_and_found.html`

### 1-4. 푸터 법적 필수 링크
- **문제**: 운영기관·개인정보처리방침·이용약관·연락처 미표시
- **조치**: 모든 페이지 하단에 법적 필수 정보 표시
- **대상 파일**: 4개 전체 (`lost_and_found.html`, `lost_and_found_admin.html`, `lost_and_found_view.html`, `qrcode.html`)

### 1-5. 이용약관 페이지 신규 생성
- **조치**: `terms_of_use.html` 신규 생성
