## 📋 원본 상태 요약

### 포함 파일

| 파일 | 설명 | 크기 |
|:---|:---|:---|
| `lost_and_found.html` | 시설 담당자 페이지 (분실물 등록·관리) | 약 93KB |
| `lost_and_found_admin.html` | 전체 관리자 대시보드 | 약 101KB |
| `lost_and_found_view.html` | 이용객 조회 전용 페이지 | 약 34KB |
| `qrcode.html` | QR코드 생성·인쇄 도구 | 약 17KB |

### 기술 스택
- React 18 (CDN, **development** 빌드)
- Tailwind CSS (CDN)
- Firebase Firestore (compat SDK 10.12.0)
- Lucide Icons, Chart.js, SheetJS
