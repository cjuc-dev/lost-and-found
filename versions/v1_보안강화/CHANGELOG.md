## 📝 변경 내역

### 1. 관리자 코드 SHA-256 해시화 🔐

> 📜 **법적 근거**
> - **개인정보보호법 제29조** (안전조치의무) — "개인정보처리자는 개인정보가 분실·도난·유출·위조·변조 또는 훼손되지 아니하도록 안전성 확보에 필요한 **기술적 조치**를 하여야 한다"
> - **개인정보의 안전성 확보조치 기준 제7조** (개인정보의 암호화) — "비밀번호는 **일방향 암호화**하여 저장하여야 한다"
> - **OWASP A07:2021** (인증 및 식별 실패) — 평문 비밀번호 저장 금지

| 구분 | v0 (이전) | v1 (변경) |
|:---|:---|:---|
| 코드 저장 | `ADMIN_CODE = "ADMIN777"` 평문 | SHA-256 해시값만 저장 (원문 비노출) |
| 인증 방식 | 문자열 직접 비교 | 입력값 → SHA-256 해시 → 해시 비교 |
| 시도 제한 | 없음 (무제한 시도 가능) | **5회 실패 시 30초 잠금** |
| 접속 로그 | 미기록 | 관리자 접속 성공 시 `activity_logs`에 기록 |

> 💡 **쉽게 말하면**: 관리자 비밀번호가 코드에 그대로 보이던 것을, 암호화된 지문(해시값)만 저장하도록 바꿨습니다. 누가 소스를 봐도 원래 비밀번호를 알 수 없습니다.

**적용 파일**: `lost_and_found.html`, `lost_and_found_admin.html`

### 2. 개인정보 처리방침 페이지 신규 생성 ⚖️

> 📜 **법적 근거**
> - **개인정보보호법 제30조 제1항** — "개인정보처리자는 개인정보 처리방침을 정하여야 한다"
> - **개인정보보호법 제30조 제2항** — "인터넷 홈페이지에 **지속적으로 게재**하여야 한다"

**신규 파일**: `privacy_policy.html` (루트에 생성)

| 조항 | 내용 |
|:---|:---|
| 제1조 | 처리 목적 — **유실물법 제11조** 근거 명시 |
| 제2조 | 보유 기간 — 수령인 정보: 반환 후 1년, 등록 정보: 3년, 접속 로그: 6개월 |
| 제3조 | 제3자 제공 제한 |
| 제4조 | 처리 위탁 — **Firebase(Google LLC)** 명시 |
| 제5조 | 파기 절차 및 방법 |
| 제6조 | 정보주체 권리 (열람·정정·삭제·처리정지) |
| 제7조 | 안전성 확보 조치 (HTTPS, SHA-256, Firebase 암호화) |
| 제8조 | 개인정보 보호 책임자 — 청주도시공사 체육시설2팀, 043-820-7242 |
| 제9조 | 처리방침 변경 시 7일 전 공지 |

> 💡 **쉽게 말하면**: "우리가 어떤 개인정보를 왜 모으고, 얼마나 보관하고, 어떻게 버리는지"를 홈페이지에 공개해야 하는 법적 의무입니다. 이걸 안 하면 과태료 대상입니다.

### 3. 수령 완료 화면 법적 근거 안내 📜

> 📜 **법적 근거**
> - **유실물법 제11조** (습득물의 반환) — 분실물 반환 시 수령인 확인 의무
> - **개인정보보호법 제15조 제1항 제2호** — "법률에 특별한 규정이 있거나 법령상 의무를 준수하기 위하여 불가피한 경우" 별도 동의 없이 수집 가능
> - **개인정보보호법 제15조 제2항** — 법적 근거로 수집하는 경우에도 "정보주체에게 **알려야** 한다"

수령 완료 처리 영역에 안내 박스 추가:

```
📖 개인정보 수집 안내 (유실물법 제11조)
분실물 반환 확인을 위해 수령인의 성함 및 연락처를 수집합니다.
수집된 정보는 반환 확인 목적으로만 사용되며, 개인정보 처리방침에 따라 관리됩니다.
```

> 💡 **쉽게 말하면**: 유실물법에 의해 수령인 정보를 수집하는 것이므로 동의 체크박스는 필요 없지만, "이런 이유로 수집합니다"라는 **안내는 해야** 합니다.

### 6. 에러 메시지 정제 (추가 개선)

> 📜 **법적 근거**
> - **OWASP A05:2021** (보안 구성 오류) — "에러 메시지를 통해 불필요한 내부 정보가 사용자에게 노출되어서는 안 된다"

| 구분 | v0 (이전) | v1 (변경) |
|:---|:---|:---|
| 에러 표시 | `"오류: " + err.message` (내부 정보 노출) | `"처리 중 오류가 발생했습니다."` (사용자 친화적) |
| 디버깅 | 없음 | `console.error('[시스템]', err)` (개발자 콘솔에만) |

> 💡 **쉽게 말하면**: 오류가 나면 "서버 DB 경로가 /artifacts/xxx/..."처럼 내부 정보가 보이던 것을, "오류가 발생했습니다"라는 간단한 안내로 바꿨습니다.
